# Git

Git adds source-control tools and GitHub authentication support to an AW Workspace. It installs git, installs the GitHub CLI, and provides a settings experience for signing in.

## What It Does

- Installs `git` and `gh` in the workspace.
- Supports GitHub sign-in through device flow or a pasted token.
- Shows authentication status in the workspace.
- Helps configure the GitHub CLI for repository work.
- Watches for uncommitted work so users can notice local changes.

## Why Use It

Use this app when a workspace needs to clone repositories, inspect history, create commits, push branches, or work with GitHub from the terminal. It is useful for both manual development and agent-driven code changes.

## How To Use It

Install the app, open its settings, and sign in to GitHub. Once authenticated, use workspace terminals or agent workflows to run git and GitHub CLI commands against repositories in the workspace.

## What It Delivers

The app gives AW Workspace a dependable source-control setup. It makes repository operations available to users and agents without requiring separate manual installation.
